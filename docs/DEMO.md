# 3 分钟演示脚本

录屏：[`demo.webm`](demo.webm)（由 `scripts/record_demo.py` 自动录制，可在改版后一键重录）。

目标：让看的人记住三件事——**版本不可变、判定有证据、变更要人批**。

## 准备

```bash
make ui                                   # 仅在改过前端时需要
.venv/bin/python -m uvicorn api.main:app --port 8020
.venv/bin/python scripts/create_user.py --username 演示 --role admin
```

浏览器打开 `http://127.0.0.1:8020/`，用刚建的账号登录。

## 时间分配

| 时间 | 画面 | 说什么 |
| --- | --- | --- |
| 0:00–0:20 | 登录页 → 工作台 | "这是一个把网络配置当证据管理的本地应用。判定由代码做，模型只负责解释。" |
| 0:20–0:50 | 导入配置 → 设基线 → 改一处 → 与基线比对 | "版本不可变，比对逐项带行号；不是整文件红绿，而是能指到第 14 行。" |
| 0:50–1:20 | 点某条漂移 → 并排对比 | "左右是基线版和当前版的原文，行号对齐，差异行高亮。" |
| 1:20–1:50 | 规则检查（含链路规则） | "4 条本机规则 + 3 条链路规则；无法判定的不会算通过。" |
| 1:50–2:20 | 点 Finding → 看原文 → 生成变更单 | "每条 Finding 都能点回原文；变更单记录创建时的证据快照。" |
| 2:20–2:45 | 提交 → 批准 → 审计卡片 | "审批人来自登录会话，不是表单里填的名字；审计只追加。" |
| 2:45–3:00 | 拓扑卡片 + 豁免徽标 | "拓扑来自登记的链路；已知偏差可以登记限时豁免，到期自动恢复。" |

## 录制时的固定动作

1. 设备下拉选 `r1-演示`（已含基线、漂移与豁免）
2. 漂移卡片点「并排对比」，停 3 秒
3. 规则卡片点「运行检查」，滚到 R005 链路 Finding
4. 生成变更单 → 提交 → 批准（对话框里填一句说明）
5. 滚到拓扑卡片，点击 `r2-演示` 节点

## 兜底方案

| 情况 | 处理 |
| --- | --- |
| 没有真实模型 key | 解释卡片用 Mock，说明"结构校验相同，模型可替换" |
| 网络不可用 | 全程不依赖外网；只有真实模型解释需要网络 |
| 浏览器不可用 | 用 `docs/ui-dashboard.png`、`ui-topology.png`、`ui-login.png` 三张截图讲 |

## 三个必须说出口的边界

- 不连接真实设备、不下发配置
- 不是中国体彩或任何官方开奖数据
- 解释层可能被拒绝；被拒绝不影响判定
