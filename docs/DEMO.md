# 60 秒演示脚本

录屏：`docs/demo.mp4`（约 36 秒，由 `scripts/record_demo.py` 自动录制；改版后一键重录；审查包不包含视频文件）。

目标：让看的人记住三件事——**判定有证据、解释可校验、变更要人批**。

## 准备

```bash
make ui                                   # 仅在改过前端时需要
.venv/bin/python -m uvicorn api.main:app --port 8020
.venv/bin/python scripts/create_user.py --username 演示 --role admin
```

浏览器打开 `http://127.0.0.1:8020/`，用刚建的账号登录。演示数据可用 `r1-演示`（含基线、漂移与豁免）。

## 分镜

| 时间 | 画面 | 说什么 |
| --- | --- | --- |
| 0:00–0:06 | 登录 → 三栏工作台 | “左边版本与采集，中间漂移与规则，右边拓扑与审计。” |
| 0:06–0:12 | 主题切换（浅色/深色） | “同一套信息层级，深色浅色都不牺牲可读性。” |
| 0:12–0:18 | 悬停漂移行号 | “行号是证据脊柱，悬停会联动右侧规则证据。” |
| 0:18–0:23 | 点击行号 → 原文定位 | “点开就是该版本的原文，目标行直接高亮。” |
| 0:23–0:28 | 并排 diff | “左右原文、行号对齐，差异到行，不是整文件红绿。” |
| 0:28–0:33 | 规则检查 + 悬停证据 | “四态判定；无法判定不会被当成通过。” |
| 0:33–0:40 | 生成变更单 → 提交 → 批准 | “审批人来自会话；审计只追加。” |
| 0:40–0:46 | 审批链 + 审计 | “创建、提交、批准、执行四个节点，驳回会断链。” |
| 0:46–0:52 | 拓扑 | “链路来自登记；不碰生产设备。” |

## 录制时的固定动作

1. 设备下拉选 `r1-演示`
2. 悬停漂移行号 1.5 秒，再点击打开原文，停 2 秒
3. 漂移卡片点「并排对比」，停 3 秒
4. 规则卡片点「运行检查」，悬停 R005 的证据行号
5. 生成变更单 → 提交 → 批准（对话框填一句说明）
6. 滚到审批链与拓扑

## 兜底方案

| 情况 | 处理 |
| --- | --- |
| 没有真实模型 key | 解释卡片用 Mock，说明“结构校验相同，模型可替换” |
| 网络不可用 | 全程不依赖外网；只有真实模型解释需要网络 |
| 浏览器不可用 | 用 `docs/ui-dashboard.png`、`ui-topology.png`、`ui-evidence-spine.png`、`ui-custody-chain.png`、`ui-login.png` 截图讲 |

## 三个必须说出口的边界

- 不写入设备；只读采集仅执行白名单 show 命令
- 不是生产运维系统，不做自动修复
- 解释层可能被拒绝；被拒绝不影响判定
